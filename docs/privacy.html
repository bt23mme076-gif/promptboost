Privacy Policy

Last updated: June 2026

PromptBoost does not collect, store, or share any personal data. Your prompts and API key never leave your device except to call the AI API you explicitly configured.

1. What We Collect

PromptBoost collects no personal information. The extension does not have analytics, telemetry, crash reporting, or any data collection mechanism built in.

2. Data Stored Locally

The following data is stored exclusively in your browser's local storage (chrome.storage) and never transmitted to any server operated by PromptBoost:

  • API key — encrypted with AES-256-GCM using a key derived from your browser's unique extension ID. Stored only on your device.
  • Settings — your chosen AI model, temperature, and shortcut preferences.
  • Prompt history — a local log of prompts you have improved, stored only on your device. You can clear or export this at any time from the extension settings.

3. Data Sent to Third-Party APIs

When you click the improve button, PromptBoost sends the text you have typed to the AI API provider you configured (Groq by default). This request:

  • Is made directly from your browser to api.groq.com
  • Uses your own API key, which you obtained from your own Groq account
  • Is governed by Groq's Privacy Policy
  • Is never routed through any PromptBoost server — there is no PromptBoost backend

PromptBoost does not see, log, or store any prompt content on any server.

4. Permissions Explained

  • storage — saves your encrypted API key, settings, and local prompt history on your device only.
  • activeTab — reads the active browser tab to locate the AI chat input field so the improve button can be injected next to it.
  • scripting — injects the improve button UI into AI chat pages you visit.
  • contextMenus — adds a right-click "Improve with PromptBoost" option when you select text on any page.
  • host_permissions (api.groq.com) — allows the extension to call the Groq API directly from your browser using your own API key.

5. No Tracking or Analytics

PromptBoost contains no tracking pixels, no analytics SDK (no Google Analytics, Mixpanel, Amplitude, or similar), and no error reporting service. We have no visibility into how you use the extension.

6. Children's Privacy

PromptBoost is not directed at children under 13. We do not knowingly collect any information from children.

7. Changes to This Policy

If this policy changes materially, the "Last updated" date at the top of this page will be updated. Continued use of the extension after changes constitutes acceptance of the revised policy.

8. Contact

Questions about this privacy policy? Open an issue on the GitHub repository or email the developer directly.
